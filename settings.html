跨裝置同步

預設情況下，「我的紀錄」只存在你正在用的這台裝置——換手機看就看不到。 想要手機和電腦看到同一份資料，就把資料同步到你自己的私人倉庫。

🔒 同步金鑰只會存在這台裝置的瀏覽器，不會傳給我、也不會進入公開倉庫。 它只用來呼叫 GitHub 的 API 讀寫你指定的那一個私人倉庫。 畫面上永遠只顯示遮罩後的樣子，隨時可以清除。
私人倉庫 格式是「帳號/倉庫名」。這個倉庫必須是 Private， 存進去的是你的持倉與交易紀錄。
同步金鑰（PAT）
還沒有金鑰？照這幾步做（約 10 分鐘）
  1. 先確認你已經有一個私人倉庫（例如 invest-data）。 沒有的話：GitHub 右上「＋」→ New repository → 名稱填 invest-data → 選 Private → Create repository。
  2. GitHub 右上角頭像 → Settings
  3. 左邊選單拉到最下面 → Developer settings
  4. Personal access tokens → Fine-grained tokens → 右上 Generate new token
  5. Token name 填 invest-watch-key； Expiration 選 1 year； Repository access 選 Only select repositories → 只勾 invest-data 這一個
  6. Permissions → Repository permissions → 找到 Contents → 改成 Read and write（其他都不要動）
  7. 按最下面綠色 Generate token → 畫面會顯示一串 github_pat_…，只會顯示這一次，整串複製起來
  8. 貼進上面的「同步金鑰」欄位 → 按「儲存並測試連線」
  9. 手機也要用的話，在手機瀏覽器打開這一頁再貼一次

⚠ 這串金鑰不要貼到聊天、文件或任何公開的地方。 萬一外流，回到步驟 4 的頁面把它 Delete 掉就作廢了——而且它本來就只能動 你勾選的那一個私人倉庫，影響有限。

備份與還原

不管有沒有開同步，都建議偶爾匯出一份備份存到你自己的雲端硬碟。 匯出的檔案含有你的持倉數字，請當成私人文件保管。
