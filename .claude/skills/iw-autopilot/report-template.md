# 停止報告（寄給 David 的信）模板

寫給程式初學者看。固定八段、順序不能換；一頁以內（不超過 40 行、2,400 個字）；不貼程式碼；除了 commit 編號不放其他程式細節。
寄出前程式會檢查格式，審查代理會再看一次好不好懂。完整的技術內容留在 `.autopilot/runs/<階段>/`，不放進信裡。

最後的「本階段使用模型…」與「安全檢查…」兩行由程式自己加，不要寫。P2 之後還有兩行也是程式加的：「驗收機：綠／紅（連結）」「外部審查（GPT）：Codex／免除／未完成；重大 n 條；採納 n、不採納 n（PR 連結）」。報告裡的測試數以驗收機為準，旁邊附本機的數字。

---

**一句話**
（一句，說結果：做完了／卡在哪裡／要你決定什麼。）

**你要決定的事**（最多 3 件；沒有就寫「沒有」）
1. （要決定什麼。選項用白話寫。我的看法：＿＿。選了會怎樣：＿＿。）

**做了什麼**（3～5 行，白話）
- …

**怎麼自己看**（給點得到的地方，不給指令）
- 網站：＿＿（哪一頁、看哪裡）
- 白話說明或完整報告：你電腦的 `.autopilot/runs/<階段>/`

**名詞解釋**（信裡出現、David 可能沒看過的詞，每個一句話）
- ＿＿：＿＿

**要繼續**：在 Claude Code 輸入　`放行 <階段>`　（還沒到合併前的停止，寫 `繼續 <階段>`）
**要修改**：在 Claude Code 輸入　`修改 <階段>：＿＿`（把要改的事寫在冒號後面）
**不確定**：把這封信轉給 Cowork。

---

三種信：

| 種類 | 什麼時候 | 「要繼續」那一行 |
|---|---|---|
| `ready` | 做完了、審查代理批准、停在合併前 | `放行 <階段>` |
| `stop` | 碰到停止條件（要他決定、被擋下、審查兩輪不過、超過時間……） | `繼續 <階段>` |
| `tier2` | 動到了要先給他看 diff 的檔 | `繼續 <階段>`（程式會把 diff 附在信的最後） |
